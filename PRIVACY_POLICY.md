# AOEM Discord Bot Privacy Policy

AOEM Discord Bot is a community utility bot for the Age of Empires Mobile Discord server. This policy explains what data the bot collects, how it is used, and how it is stored.

## Data Collected

The bot collects only the data necessary to support its features.

- Discord user ID and username
- User-provided report text in bug reports, suggestions, and translation issue reports
- Optional screenshot URLs attached during report submission
- Invite tracking data to manage server join sources
- Message content for translation features when a user reacts to eligible messages

## How Data Is Used

The bot uses collected data for the following purposes:

- Storing and managing community bug reports, suggestions, and translation issue reports
- Sending translated text to users who request translation via message reaction
- Tracking server invite usage for leaderboard and moderation functions
- Logging member join and leave events for server administration

## Data Storage

The bot stores some data outside of Discord:

- Google Sheets is used to store report content and related metadata
- Local SQLite databases store invite and member tracking information
- ImgBB stores user-uploaded screenshot images when report attachments are provided

## External APIs

The bot uses the following external services:

- Google Sheets API for report storage and retrieval
- ImgBB API to upload screenshot images provided by users
- A translation API to translate user-requested message content

## Privacy and User Control

- Participation is voluntary. Users can avoid submitting message content by not using the report or translation features.
- The bot does not sell user data.
- Message content is not used to train machine learning or AI models.

## Message Content and AI Training

The bot does not use message content for AI training.
Message content is only processed in real time for bot features and stored only when a user submits it as part of a report.

## Contact

If you have questions about this privacy policy, contact the server administrators or bot owners.
